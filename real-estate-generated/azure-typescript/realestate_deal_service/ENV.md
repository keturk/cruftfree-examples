# Environment Variables

## Quick Start

1. Copy `.env.example` to `.env`
2. Update values for your environment
3. Start services: `docker compose up -d`

### Secrets Configuration

#### `SECRETS_BACKEND`
- **Required:** Optional
- **Default:** `environment`
- **Description:** Secrets provider backend (environment, vault, aws)

#### `jwt_public_key` (secret handle)
- **Required:** Required when the system declares gateway JWT auth and this service hosts the static-key verify endpoint
- **Default:** (none)
- **Description:** The PEM public key, resolved through the secrets backend on each verification; never read from a path named by an environment variable. The pinned algorithm, issuer and audience are baked from the system gateway config at generation time; no environment variable overrides them.

### OpenTelemetry (OTLP)

#### `OTEL_EXPORTER_OTLP_ENDPOINT`
- **Required:** Optional when tracing is enabled in system observability
- **Default:** From system tracing configuration, or set by Docker Compose for platform-managed Jaeger
- **Description:** When set, overrides the configured OTLP URL before the exporter is created. The value is the collector's OTLP/HTTP base URL (port 4318 on a platform-managed Jaeger); traces are posted to its `/v1/traces` path. If exporter setup fails (invalid URL, unreachable collector), the service logs ``tracing_setup_failed`` and continues without exporting traces.
