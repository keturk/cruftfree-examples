### OpenTelemetry (OTLP)

#### `OTEL_EXPORTER_OTLP_ENDPOINT`
- **Required:** Optional when tracing is enabled in system observability
- **Default:** From system tracing configuration, or set by Docker Compose for platform-managed Jaeger
- **Description:** When set, overrides the configured OTLP URL before the exporter is created. The value is the collector's OTLP/HTTP base URL (port 4318 on a platform-managed Jaeger); traces are posted to its `/v1/traces` path. If exporter setup fails (invalid URL, unreachable collector), the service logs ``tracing_setup_failed`` and continues without exporting traces.
